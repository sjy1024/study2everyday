# 每日学习记录

建议每日新增一份记录文件，统一放在这里。

## 文件命名建议
- `2026-11-02.md`
- `2026-11-02-esp32-learning.md`

## 示例记录
```markdown
# 日期：2026-11-02

## 学习主题
Git 基础使用

## 学习内容
- 学习 Git 基本概念
- 练习分支创建与切换
- 了解仓库结构与提交记录

## 重点知识
- `git checkout` 与 `git switch` 的区别
- `main`、`develop`、`feature/*` 分支职责

## 遇到的问题
- 初次使用 Git 对提交和分支概念还不熟悉

## 解决思路
- 仔细阅读 README
- 通过实际创建分支和提交来加深理解

## 今日收获
- 对 Git 工作流有了更清晰的认识
```
