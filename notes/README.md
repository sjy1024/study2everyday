# 学习笔记

这里用于记录每天的学习内容与总结。

## 目录说明
```text
notes/
├── README.md
├── daily/
│   └── README.md
└── templates/
    └── study-note-template.md
```

## 使用建议
- 每天新增一份 `daily/` 下的记录文件
- 记录格式建议包含：日期、主题、学习内容、重点、问题、收获
- 若某天内容较多，可以拆成多个文件，方便后续查阅

-
