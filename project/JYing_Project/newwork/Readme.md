# AI / 嵌入式 / 汽车 / 机器人 / 医疗 行业资讯日报

一个每天自动跑的资讯小工具：抓取 6 个领域的行业新闻，存成表格和网页。

---

## 一、我每天要做什么？

**什么都不用做。** 电脑开着并登录的情况下，每天 **09:30** 会自动抓一次（电脑关机就跳过当天）。

想看的时候，双击这个文件就行：

> **`index.html`** —— 用浏览器打开，就是当天的资讯页

---

## 二、手动抓取：双击 `运行.bat`

想立刻刷新，或今天自动任务没跑成，双击根目录的 **`运行.bat`**：

- 会弹出一个黑色窗口，跑约 1～2 分钟；
- 结束后显示「新增多少条 / 各领域分布 / 成功几个源」；
- 按任意键关闭，然后双击 `index.html` 就能看到最新内容。

> `运行.bat` 会自动抓取 + 更新网页，不用再点别的。
> 想抓更多天：在该目录按住 Shift 右键 →「在此处打开 PowerShell」，执行
> `.\运行.bat --days 7`。

## 五、常见问题

**Q：打开网页是旧内容？**
说明今天还没抓到新数据。双击 `运行.bat` 跑一次即可。

**Q：`运行.bat` 窗口闪一下就没了 / 报错？**
看 `worknews\logs\` 里当天的日志；也可能是 Python 环境被改动。正常情况下窗口会停住显示错误，按任意键才关。

**Q：某个网站没抓到？**
单个源失败是正常的（反爬、临时故障）。窗口末尾会列「本次失败的源」，不影响其他资讯。

**Q：摘要空白 / 时间显示「未知」？**
部分中文站点没有 RSS，只能从列表页取到标题和链接，没有摘要和时间，属正常。

**Q：想改自动运行时间？**
见 `Demo\README.md` 第 7 节，一条命令重注册任务即可。

**Q：自动任务没跑？**
只有在「电脑开机 + 已登录该用户」时才会执行；关机、休眠、未登录都会跳过，且不会补跑。
