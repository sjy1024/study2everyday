# 项目练习记录

这里用于存放个人小项目的代码、思路和记录。

## 目录说明
```text
project/
├── README.md
├── project-template/
│   └── README.md
└── <你的项目名>/
```

## 项目记录建议
每个项目可以包含：
- 项目目标
- 需求说明
- 实现思路
- 关键代码
- 遇到的问题
- 测试结果

## 示例结构
```text
project/
├── README.md
├── esp32-led-demo/
│   ├── README.md
│   └── main.cpp
└── stm32-gpio-test/
    ├── README.md
    └── main.c
```

## 推荐项目清单
- STM32 小实验
- ESP32 控制项目
- 传感器/按键控制 demo
- 电子开发相关学习脚本
